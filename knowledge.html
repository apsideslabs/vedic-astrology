AHow the engine uses this

Every rule the reading applies carries an id and a chapter reference, so a statement in a chart can be traced back to a page here. The rule ids live in src/jyotish/interpret.py; the data tables the engine runs on — exaltations, moolatrikonas, friendships, house significations, the gochara cells — are in src/jyotish/zodiac.py and src/jyotish/transits.py. The browser build shares them through site/assets/js/data.js, which is generated from the Python source so the two cannot drift apart.
