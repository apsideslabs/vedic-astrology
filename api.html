API and CLI

The site runs the engine in your browser. The same engine ships as a Python package with a FastAPI service and a command-line client, for when you want it server-side.

01Run it

git clone https://github.com/apsideslabs/vedic-astrology.git
cd vedic-astrology
pip install -r requirements.txt

uvicorn app.main:app --reload      # http://127.0.0.1:8000  (docs at /docs)
python -m jyotish.cli --date 1990-04-14 --time 08:15 \
    --lat 13.0827 --lon 80.2707 --tz 5.5 --place Chennai
python -m pytest tests -q          # 34 tests

02POST /api/chart

{
  "date": "1990-04-14",
  "time": "08:15",
  "latitude": 13.0827,
  "longitude": 80.2707,
  "tz_offset": 5.5,
  "place": "Chennai",
  "name": "",
  "ayanamsa": "lahiri",          // or "raman_397"
  "house_system": "whole_sign"   // or "sripati", "equal"
}

The response carries birth, ayanamsa, lagna, planets (nine, with sign, degree, nakshatra, pada, navamsa, house, dignity, combustion, retrogression and a strength breakdown), houses, panchanga, vimshottari with bhuktis, yogas, aspects, transits and interpretation.

Every interpretation statement is {rule, text, source} — the rule id and the chapter, so a reading can be audited rather than trusted.

03Library use

from jyotish import BirthData, build_chart
from jyotish import interpret, transits

birth = BirthData(date="1990-04-14", time="08:15",
                  latitude=13.0827, longitude=80.2707,
                  tz_offset=5.5, place="Chennai")
chart = build_chart(birth, ayanamsa="lahiri", house_system="whole_sign")

chart.lagna_sign                 # 'Taurus'
chart.planets["Moon"].dignity    # 'debilitated'
chart.vimshottari["current"]     # running mahadasha and bhukti

reading = interpret.interpret(chart, transits.analyse(chart))

On the ephemeris: the industry standard is the Swiss Ephemeris (pyswisseph), which implements about forty ayanamsas natively. It is a C extension. ephemeris.py is a thin adapter returning {planet: {longitude, latitude, speed}} and nothing else, so swapping it in is a one-function change.
